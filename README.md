# مدیریت کلاس

برنامه‌ی وب مدیریت کلاس (حضور و غیاب، نمرات، کارنامه). یک صفحه‌ی ایستا است و روی GitHub Pages اجرا می‌شود.

## انتشار روی GitHub Pages
1. در GitHub یک مخزن (Repository) جدید بسازید.
2. همه‌ی فایل‌های این پوشه را در ریشه‌ی مخزن آپلود کنید (`Add file ← Upload files`)، به‌همراه فایل `.nojekyll`.
3. به `Settings ← Pages` بروید. در بخش Source گزینه‌ی `Deploy from a branch` را انتخاب کنید، شاخه‌ی `main` و پوشه‌ی `/ (root)` را بزنید و Save کنید.
4. بعد از یکی دو دقیقه آدرس سایت نمایش داده می‌شود: `https://USERNAME.github.io/REPO/`

## نصب روی گوشی
صفحه را در مرورگر باز کنید و «افزودن به صفحه‌ی اصلی» را بزنید؛ مثل یک برنامه با آیکون تخته‌سیاه نصب می‌شود.

## ورود دانش‌آموزان (Supabase)
یک بار فایل `cm-portal.sql` را در Supabase اجرا کنید (`SQL Editor ← New query ← Run`). این فایل جدول و تابع‌های ورود دانش‌آموز را می‌سازد. پس از آن در برنامه، حساب‌های دانش‌آموزان را دوباره بسازید یا رمزشان را به‌روزرسانی کنید و «انتشار کارنامه‌ها» را بزنید.
